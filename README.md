# ADMIN 랜딩페이지

충남대학교 동아리 ADMIN 소개 페이지. 빌드 도구 없이 HTML·CSS·JS 파일만으로 동작합니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 페이지 뼈대. 섹션 순서를 바꿀 때만 건드립니다. |
| **`data.js`** | **모든 글과 사진 경로. 평소 내용 수정은 이 파일만 고치면 됩니다.** |
| `style.css` | 디자인. 색·여백·글자 크기. |
| `app.js` | `data.js`의 내용을 `index.html`에 채워 넣는 스크립트. |
| `images/` | 사진 폴더. |

## 로컬에서 열어보기

`index.html`을 더블클릭해 브라우저로 열면 바로 보입니다. 별도 서버가 필요 없습니다.

서버로 띄워보고 싶다면:

```bash
cd cnu-admin
python3 -m http.server 8000     # http://localhost:8000
```

## data.js에서 뭘 고치면 어디가 바뀌나

### `site` — 첫 화면 / 고정 바

| 항목 | 바뀌는 곳 |
| --- | --- |
| `site.name` | 왼쪽 위 작은 로고, 첫 화면의 큰 ADMIN 글자, 브라우저 탭 제목 |
| `site.affiliation` | 큰 글자 위의 작은 회색 글씨 |
| `site.tagline` | 큰 글자 아래, 가로선 밑 한 줄 소개 |
| `site.cta` | 첫 화면 버튼. `label`은 글자, `href`는 이동할 곳 |
| `site.nav` | 오른쪽 위 메뉴. `href`는 `index.html`의 `id`와 같아야 합니다 (`#about`, `#activities`, `#events`, `#awards`, `#members`, `#join`) |

### `about` — 01 소개

| 항목 | 바뀌는 곳 |
| --- | --- |
| `label` | 왼쪽 세로 라벨 글자 (번호는 HTML에 있습니다) |
| `heading` | 소개 섹션 큰 제목 |
| `paragraphs` | 소개 문단. **첫 문단만 조금 크고 진하게** 표시됩니다 |
| `letters` | ADMIN 다섯 글자의 뜻. `letter`(큰 글자), `word`(단어), `desc`(설명) |

### `activities` — 02 활동

`groups`에 칸을 넣습니다. `name`(학습, 친목 같은 칸 이름) + `items`(`title`, `desc`, `image`). `desc`는 비워 둘 수 있습니다. 항목은 사진 카드로 나오며, 넓은 화면에서는 한 줄에 3칸씩 놓입니다. 사진이 두 장이면 `image` 대신 `images: ["...", "..."]` 로 적습니다. 그 카드는 두 칸을 차지합니다.

### `events` — 03 기록

| 항목 | 바뀌는 곳 |
| --- | --- |
| `label`, `heading` | 섹션 라벨, 큰 제목 |
| `list` | 행사 목록. `title`(행사명), `date`(날짜), `place`(장소), `desc`(설명), `image`(사진 경로, 없어도 됩니다) |

- 적은 순서대로 나옵니다. 날짜 순서로 적어 주세요.
- 날짜는 `2026.03.10`, `2026.05`, `2026.04.01 – 04.02` 형식으로 적습니다.
- 날짜가 지나지 않은 행사에는 **예정** 표시가 자동으로 붙습니다.

### `awards` — 04 성과

`list`에 최근 순서로 넣습니다. `year`(연도), `title`(대회·학회 이름), `result`(상 이름이나 "논문 발표").

### `members` — 05 운영진 (조직도)

**사진을 쓰지 않습니다.** 이름·직책·학번·한 줄 소개만 들어갑니다.

| 항목 | 바뀌는 곳 |
| --- | --- |
| `label`, `heading`, `note` | 섹션 라벨, 큰 제목, 제목 밑 회색 안내문 |
| `lead` | **맨 위 굵은 줄 아래 크게 나오는 대표 운영진.** 회장·부회장·총무처럼 3~4명 권장 |
| `departments` | 그 아래 부서별 목록. `name`(부서 이름) + `people`(그 부서 사람들) |

사람 하나는 이렇게 생겼습니다. `lead` 와 `departments[].people` 둘 다 같은 모양입니다.

```js
{ name: "김호성", role: "회장", year: "22학번", bio: "동아리 운영 전반을 맡고 있습니다." }
```

| 필드 | 내용 | 없으면 |
| --- | --- | --- |
| `name` | 이름 (굵게) | **필수** |
| `role` | 직책. 이름 옆 작은 회색 글씨 | **필수** |
| `year` | 학과·학번 | 그 줄만 빠짐 |
| `bio` | 한 줄 소개 | 그 줄만 빠짐 |

- `lead` 는 인원 수대로 가로로 배치됩니다 (최대 4열). 모바일에서는 세로로 쌓입니다.
- 부서를 추가하려면 `departments` 에 `{ name: "...", people: [...] }` 를 넣으면 됩니다. 줄이 자동으로 늘어납니다.
- 부서에 `desc: "..."` 를 넣으면 부서 이름 아래에 작은 설명이 붙습니다. 안 넣어도 됩니다.
- 부서원은 인원에 맞춰 가로로 나뉩니다. 2명이면 2칸, 3명이면 3칸.

### `join` — 06 가입 안내

| 항목 | 바뀌는 곳 |
| --- | --- |
| `label`, `heading`, `note` | 섹션 라벨, 큰 제목, 안내문 |
| `steps` | 신청 단계. `title` + `desc`. 번호는 자동으로 붙습니다 |
| `details` | 회비 같은 안내 목록. `label` + `value` + `href`(링크, 비워두면 글자만 표시) |
| `cta` | 가입 버튼 |

**계좌번호와 개인 전화번호는 이 페이지에 적지 않습니다.**

### `contact` — 07 연락 (하단)

| 항목 | 바뀌는 곳 |
| --- | --- |
| `label`, `heading`, `note` | 하단 라벨, 큰 제목, 안내문 |
| `details` | 왼쪽 연락처 목록. `label`(왼쪽 회색 글씨) + `value`(내용) + `href`(링크, 비워두면 글자만 표시) |
| `links` | 오른쪽 SNS 목록. 구조는 `details`와 같습니다 |
| `copyright` | 맨 아래 줄. 연도는 자동으로 붙습니다 |

## 사진 넣기

`images/` 폴더에 `event-1.jpg` 형식으로 넣고, `data.js`의 `image` 값과 파일명을 맞춥니다.

- 활동: `event-1`~`event-5`는 학습, `event-6`~`event-11`은 친목입니다. 파일이 없으면 회색 박스에 파일명이 표시되고, 사진을 넣으면 자동으로 사라집니다.
- 기록: 필요한 행사에만 `image`를 추가합니다. 없으면 글만 나옵니다.
- 사진은 **가로**가 가장 잘 맞습니다. 비율이 달라도 잘려서 채워집니다.
- 사진은 **흑백으로 보이다가 마우스를 올리면 색이 돌아옵니다.** 이 효과를 끄려면 `style.css`의 `.ph img`에서 `filter: grayscale(1) ...` 줄을 지우세요.

## 색과 글자 크기 바꾸기

`style.css` 맨 위 `:root`에 색이 모여 있습니다.

```css
--paper:     #f5f5f3;   /* 배경 */
--ink:       #151513;   /* 본문 글자 */
--ink-2:     #4d4d49;   /* 보조 텍스트 */
--ink-3:     #8c8c86;   /* 라벨·캡션 */
--line:      #d6d6d0;   /* 구분선 */
--ph:        #dcdcd6;   /* 사진 자리 회색 */
--sec-pad:   clamp(72px, 11vh, 150px);  /* 섹션 위아래 여백 */
```

`style.css`를 고치면 `index.html`의 `style.css?v=` 뒤 숫자를 하나 올려 주세요. 서버가 CSS를 30일간 캐시하기 때문입니다.

폰트는 Pretendard를 CDN으로 불러옵니다(`index.html` 위쪽 `<link>`). 인터넷이 없는 환경이면 시스템 고딕으로 자동 대체됩니다.
