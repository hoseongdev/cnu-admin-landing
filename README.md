# ADMIN 랜딩페이지

충남대학교 동아리 ADMIN 소개 페이지. 빌드 도구 없이 HTML·CSS·JS 파일만으로 동작합니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 페이지 뼈대. 섹션 순서를 바꿀 때만 건드립니다. |
| **`data.js`** | **모든 글과 사진 경로. 평소 내용 수정은 이 파일만 고치면 됩니다.** |
| `style.css` | 디자인. 색·여백·글자 크기. |
| `app.js` | `data.js`의 내용을 `index.html`에 채워 넣는 스크립트. |
| `images/` | 사진 폴더. |

## 로컬에서 열어보기

`index.html`을 더블클릭해 브라우저로 열면 바로 보입니다. 별도 서버가 필요 없습니다.

서버로 띄워보고 싶다면:

```bash
cd cnu-admin
python3 -m http.server 8000     # http://localhost:8000
```

## data.js에서 뭘 고치면 어디가 바뀌나

### `site` — 맨 위 / 고정 바

| 항목 | 바뀌는 곳 |
| --- | --- |
| `name` | 왼쪽 위 작은 로고, 첫 화면의 큰 ADMIN 글자, 브라우저 탭 제목 |
| `affiliation` | 큰 글자 위의 작은 회색 글씨 (충남대학교) |
| `tagline` | 큰 글자 아래, 가로선 밑 한 줄 소개 |
| `nav` | 오른쪽 위 메뉴. `label`은 보이는 글자, `href`는 이동할 섹션. `href`는 `index.html`의 `id`와 같아야 합니다 (`#about`, `#members`, `#events`, `#contact`) |

### `about` — 01 소개

| 항목 | 바뀌는 곳 |
| --- | --- |
| `label` | 왼쪽 세로 라벨 글자 (번호 `01`은 HTML에 있습니다) |
| `heading` | 소개 섹션 큰 제목 |
| `paragraphs` | 소개 문단. 배열에 문자열을 넣는 만큼 문단이 늘어납니다. **첫 문단만 조금 크고 진하게** 표시됩니다 |
| `activities` | 아래쪽 가로줄 목록. `title`(왼쪽 굵은 글씨) + `desc`(오른쪽 설명). 항목을 더하면 줄이 늘어납니다 |

### `members` — 02 임원진

| 항목 | 바뀌는 곳 |
| --- | --- |
| `label`, `heading`, `note` | 섹션 라벨, 큰 제목, 제목 밑 회색 안내문 |
| `list` | 임원 카드. 한 사람당 `name`(이름), `role`(직책, 사진 아래 작은 글씨), `year`(학과·학번), `bio`(한 줄 소개), `image`(사진 경로) |

열 수는 인원 수에 맞춰 자동으로 정해집니다. 4명 이하면 한 줄, 5~6명이면 두 줄(3열)로 나옵니다. 모바일에서는 2열.
`year`나 `bio`를 지우면 그 줄만 빠집니다.

### `events` — 03 행사

| 항목 | 바뀌는 곳 |
| --- | --- |
| `label`, `heading` | 섹션 라벨, 큰 제목 |
| `list` | 행사 목록. `title`(행사명), `date`(날짜), `place`(장소, 날짜 옆 회색 글씨), `desc`(설명), `image`(사진 경로) |

**크기는 순서대로 자동으로 달라집니다.** 1번째는 큰 가로형, 2·3번째는 2단, 4번째는 사진 왼쪽·글 오른쪽, 5·6번째는 다시 2단. 7개 이상이면 이 순서가 반복됩니다.

특정 행사의 크기를 직접 정하고 싶으면 그 항목에 `size`를 추가하세요.

```js
{ title: "...", date: "...", size: "lg", image: "images/event-1.jpg" }
```

| `size` | 모양 |
| --- | --- |
| `"lg"` | 가로 전체, 사진 크게 |
| `"md"` | 절반 너비 (기본) |
| `"side"` | 사진 왼쪽 + 글 오른쪽 |
| `"sm"` | 1/3 너비, 정사각형 사진 |

### `contact` — 04 연락 (하단)

| 항목 | 바뀌는 곳 |
| --- | --- |
| `label`, `heading`, `note` | 하단 라벨, 큰 제목, 안내문 |
| `details` | 왼쪽 연락처 목록. `label`(왼쪽 회색 글씨) + `value`(내용) + `href`(링크, 비워두면 글자만 표시) |
| `links` | 오른쪽 SNS 목록. 구조는 `details`와 같습니다 |
| `copyright` | 맨 아래 줄. 연도는 자동으로 붙습니다 |

## 사진 넣기

`images/` 폴더에 `member-1.jpg`, `event-1.jpg` 형식으로 넣고, `data.js`의 `image` 값과 파일명을 맞춥니다.

- 임원진 사진은 **세로 3:4**, 행사 사진은 **가로**가 가장 잘 맞습니다. 비율이 달라도 잘려서 채워집니다.
- 파일이 없으면 회색 박스에 파일명이 표시됩니다. 사진을 넣으면 자동으로 사라집니다.
- 사진은 **흑백으로 보이다가 마우스를 올리면 색이 돌아옵니다.** 이 효과를 끄려면 `style.css`의 `.ph img`에서 `filter: grayscale(1) ...` 줄을 지우세요.

## 색과 글자 크기 바꾸기

`style.css` 맨 위 `:root`에 색이 모여 있습니다.

```css
--paper:     #f5f5f3;   /* 배경 */
--ink:       #151513;   /* 본문 글자 */
--ink-2:     #4d4d49;   /* 보조 텍스트 */
--ink-3:     #8c8c86;   /* 라벨·캡션 */
--line:      #d6d6d0;   /* 구분선 */
--ph:        #dcdcd6;   /* 사진 자리 회색 */
--sec-pad:   clamp(72px, 11vh, 150px);  /* 섹션 위아래 여백 */
```

폰트는 Pretendard를 CDN으로 불러옵니다(`index.html` 위쪽 `<link>`). 인터넷이 없는 환경이면 시스템 고딕으로 자동 대체됩니다.
